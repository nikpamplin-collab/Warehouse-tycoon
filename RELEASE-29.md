# Warehouse Tycoon DOTv29

- Home uses the Compact Block layout: one continuous building, a consistent view of the landscaped plot, and additional frontage reserved for the loading bays. Plots larger than 100,000 sq ft can be explored with the arrows at the same scale. Under-construction floor area appears in place before it opens.
- Automated capacity dots again show the robot icon. Commissioned automation has a metal frame, mesh on the front and side, and subtle status lights. These stop with Pause motion or Reduced Motion.
- Bids keeps live prices, fit, quantities and actions in view; the detailed rules are available via info buttons. Finances has three sections: Trading, Contracts and Company.
- Portrait remains the default. No reviewer or roadmap changes, and no changes to simulation, prices, lending, bidding or time.
- Refresh while online. v29 imports the v28 save (or the latest supported older save) into a separate save slot, leaving the original intact. Rollback target: the unchanged release/DOTv28 branch.
